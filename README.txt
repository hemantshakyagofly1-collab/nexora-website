IMPORTANT BEFORE PUBLISHING:

2. Replace YOUR_EMAIL@example.com with the real email address NEXORA should receive enquiries at.
3. Save the file.

CONTACT FORM:
The contact form currently opens the visitor's email application (mailto). It does not send enquiries to a server automatically. A backend or form service can be connected later.

DEPLOYMENT:
This is a static HTML/CSS/JavaScript site. In Vercel Project Settings > Build and Deployment:
- Framework Preset: Other
- Build Command: leave default/empty (do not override)
- Output Directory: leave empty/default unless Vercel requires a value
- Install Command: leave default/empty
Upload/commit all files and folders to the ROOT of the existing GitHub repository (same level as index.html). Do not upload the ZIP itself without extracting it.

No fake client logos, reviews, or performance statistics are included. The Case Studies page clearly labels project stories as coming soon.
